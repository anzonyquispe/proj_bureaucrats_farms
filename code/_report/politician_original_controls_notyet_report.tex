\begin{abstract}
This report compares 32 fixed-effect specifications using Legacy not-yet/partial-zero-spell controls. Each specification presents the baseline politician event study for event years -5 through 4, with -1 omitted, before and after pretrend rotation. It also presents one non-rotated DiD interaction plot for \texttt{post} $\times$ \texttt{treat} $\times$ \texttt{downup\_ac\_pop}, following \texttt{\_app\_19\_polischar\_fe12\_did\_downup\_inter\_plot.do}.
\end{abstract}
