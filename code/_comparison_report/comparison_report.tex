% \safefig{<bare basename, no extension>}{<width>}{<caption-line>}
% Tries the basename across the registered \graphicspath dirs. If the file
% does not exist, prints an inline "(pending: <basename>)" note instead of
% breaking the build.
\newcommand{\safefig}[3]{%
  \IfFileExists{\dCDHplots/#1.png}{%
    \includegraphics[width=#2]{#1.png}%
  }{%
    \IfFileExists{\figdir/#1.png}{%
      \includegraphics[width=#2]{#1.png}%
    }{%
      \fbox{\parbox[c][0.6\linewidth][c]{0.95\linewidth}{%
        \centering\color{red}\textit{(pending: #1.png)}%
        \\[0.3em]\tiny#3%
      }}%
    }%
  }%
}

    \centering
    \safefig{dCDH_#1_#2_#3}{\linewidth}{dCDH_#1_#2_#3}
    \caption*{\scriptsize #4}
  \end{subfigure}%
}

\noindent
This document compares results obtained with the original treatment
\texttt{downup\_ac} and the population-weighted variant
\texttt{downup\_ac\_pop}, across the two non-rural-replication branches of
the project: the dynamic-DiD estimator of de~Chaisemartin \& d'Haultf\oe{}uille
(dCDH) and the stacked event study. Rural replication results are documented
separately in
\texttt{\dropboxroot/tex/paper/tables/\_comparison\_downup\_ac\_vs\_acpop.pdf}.

Missing figures are flagged inline as
\fbox{\color{red}\textit{(pending: \dots)}} so the document compiles even while
some jobs are still running.

% ===========================================================================
\section{dCDH event study (de Chaisemartin \& d'Haultf\oe{}uille)}
% ===========================================================================

\noindent
Plots produced by \texttt{code/dCDH\_analysis/plot\_dCDH\_event\_study.R} from
the per-fit CSVs at \texttt{data\_output/intermediate/dCDH/}. The top-left
label on each panel reports the Average Total Effect (ATE) and its standard
error. Within each section the first two panels show \texttt{downup\_ac}
(original) and the last two show \texttt{downup\_ac\_pop} (population-weighted);
within each treatment the left panel omits the AC trend and the right panel
adds \texttt{trends\_nonparam = ['ac\_uq\_id']} (i.e.\ ac$\times$monthyear
linear trend).
