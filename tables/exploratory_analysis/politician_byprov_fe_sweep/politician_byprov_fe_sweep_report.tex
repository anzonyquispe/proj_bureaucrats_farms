\begin{abstract}
This report compares 32 fixed-effect specifications. For each specification, the top row presents the baseline politician event study for event years -5 through 4, with -1 omitted, before and after pretrend rotation. The lower panel presents the DiD interaction of \texttt{post} $\times$ \texttt{treat} $\times$ \texttt{downup\_ac\_pop}, constructed following \texttt{\_app\_19\_polischar\_fe12\_did\_downup\_inter\_plot.do}. 
The prior event-time interaction with \texttt{downup\_ac\_pop} is not included. Rotated pre-period and post-period averages are computed from the rotated coefficients with the corresponding transformed covariance matrix.
\end{abstract}
